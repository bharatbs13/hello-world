# FR-074 — Enterprise IAM / SSO Federation

## Target Version
v0.7

## Scope

Defines enterprise identity federation support for governed Relix access systems.

This FR integrates enterprise authentication and authorization ecosystems into Relix governance flows.

Covers:

- SSO integration
- IAM federation
- enterprise identity propagation
- role-aware execution governance
- organizational access mapping
- identity-based connector policy enforcement

Does NOT yet cover:

- adaptive identity trust scoring
- biometric authentication
- decentralized identity systems
